# TV Masjid Qiblatin

Display TV masjid fullscreen 16:9 (1920x1080, auto-scale vh/vw): jam, tanggal Masehi + Hijriah,
jadwal sholat hitung lokal Kemenag (offline, tanpa API), countdown, Adzan Mode
(Adzan → Sunnah → Iqamah → Sholat Fardhu), panel kegiatan, running text petugas Jumat, Ramadhan built-in 1447-1449.

Buka `index.html` di browser TV (atau serve: `python -m http.server 8812`).
Edit kegiatan di `KEGIATAN`, petugas Jumat di `JUMAT`, durasi di `GAP`/`FARDHU`.
